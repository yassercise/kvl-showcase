# KVL Showcase

Touchscreen brochure demo for Kanoo Vehicle Leasing. Static site, no build step.

## Host on GitHub Pages
1. Create a repo, upload everything in this folder (keep the `img` folder).
2. Settings > Pages > Deploy from branch > `main` / root.

## Edit
- Cars, trims, colours, specs: the `CARS` array in `index.html`.
- Images: `img/`, one file per colour. Add a file, then add its name to the `IMG` map at the top of the script.
